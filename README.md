# Mahindra Thar — Interactive 3D Showcase

An immersive, modern web experience celebrating the iconic Mahindra Thar. Built with React 19, TypeScript, Tailwind CSS, Framer Motion, and GSAP.

## Features

- **Interactive Visual Showcase:** Frame-by-frame scroll animations and dynamic vehicle perspectives.
- **Custom UI Experience:** Custom cursor, marquee highlights, responsive navigation, and modern dark aesthetics.
- **Interactive Modals:** Vehicle configuration, booking inquiries, and user authentication layers.
- **Smooth Animations:** Powered by GSAP and Framer Motion.

## Tech Stack

- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion & GSAP
- **Icons & Utilities:** Lucide React, clsx, tailwind-merge

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm / yarn / pnpm

### Installation

```bash
npm install
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build

```bash
npm run build
```
